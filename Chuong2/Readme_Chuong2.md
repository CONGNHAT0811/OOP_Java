1. Kiểu dữ liệu nguyên thủy  
   * **Kiểu số**:  
     - Kiểu số nguyên: `byte`, `short`, `int`, `long`  
     - Kiểu ký tự: `char`
     - Kiểu số thực: `float`, `double`  
   * **Kiểu logic**: `boolean`  

2. Kiểu dữ liệu tham chiếu  
   * **Kiểu Array**: Cấu trúc dạng mảng, lưu trữ các phần tử cùng kiểu dữ liệu.  
   * **Kiểu Class**: Cấu trúc dạng lớp đối tượng do người dùng định nghĩa, bao gồm thuộc tính và phương thức.  
   * **Kiểu Interface**: Định nghĩa các phương thức trừu tượng mà các lớp triển khai phải thực hiện.  

3. Ví dụ minh họa:  
   ```java
   // Kiểu dữ liệu nguyên thủy
   int age = 25; // Số nguyên
   double salary = 5000.75; // Số thực
   boolean isActive = true; // Logic

   // Kiểu dữ liệu tham chiếu
   String name = "Nguyen Van A"; // Chuỗi
   int[] numbers = {1, 2, 3, 4, 5}; // Mảng

4. Cấu trúc điều khiển chương trình 
**Cấu trúc tuần tự**: 1 dạy các câu lệnh các hàm được thực hiện tuần tự 
**Cấu trúc lặp** các vòng lặp for, do(Câu lệnh) while(điều kiện), while(Diều kiện, câu lệnh)
**Cấu trúc tuyển trọn** Điều kiện rẽ nhanh if else , swith-case
